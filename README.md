
# Advanced Password Analyzer

## Project Overview
Advanced Password Analyzer is a Python-based GUI application developed using Tkinter. It analyzes password strength and helps users create stronger passwords.

## Features
- Password strength analysis
- Password strength percentage
- Entropy-based password evaluation
- Strong password generator
- Show/Hide password option
- Minimum 6 characters requirement
- Scanning animation with a hacker-themed interface

## Technologies Used
- Python
- Tkinter

## Project Objective
To help users understand password security and create strong passwords to improve their online safety.
